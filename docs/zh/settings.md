# 设置说明

在 **设置** 页通过左侧分组调整：常规、外观、网络、环境、内核、终端、快捷键、Webview、关于。

## 常规（General）

- **工作目录**：dsh 启动所在目录；留空用配置目录下的 `workspace`。
- **端口**：自动（推荐，从 3080 起挑空闲端口）或手动指定。
- **关闭按钮行为**：隐藏到托盘或直接退出；可选择「每次询问」或「记住选择」。

### 新标签页与搜索

- **默认搜索引擎**：地址栏输入非网址内容、以及内置导航页搜索时使用的引擎（百度 / 搜狗 / 360 / Bing / Google / DuckDuckGo）。
- **新标签页**：点标签条「＋」时打开什么——**内置导航页**（带搜索框与常用站点）或**自定义网址**（填写固定 URL）。
- **常用站点快捷方式**：名称 + 网址的列表，显示在内置导航页上，点击直达。

### 其它

- **恢复默认设置**：一键重置并重启 dsh。

## 外观（Appearance）

- **主题**：跟随系统 / 浅色 / 深色，切换即时生效。
- **配色方案**：7 套预制方案（默认蓝 / 极客紫 / 森林绿 / 青碧 / 暖橙 / 玫瑰红 / 石墨灰），每套同时决定**主色**与**页面 / 侧栏底色**，深浅两套自动适配（切换「主题」时配色跟着重算）。明暗仍由上面的「主题」控制，「默认蓝」保持原观感。
- **语言（二级下拉）**：选择 中文 / English，并选择扩展翻译（zh：简体/二次元/文言/繁体中文；en：English/海盗腔/莎翁腔）。扩展翻译为**文本覆盖**，仅当前语言生效，不改 dsh 设置。
- **界面缩放**：50%~200%（作用于外壳窗口与内嵌 webview）。
- **禁用系统缩放**：开启会提示重启生效（忽略操作系统显示缩放）。

## 网络（Network）

- **npm 镜像源**：官方 registry / npmmirror。
- **代理**：启用 + 协议(HTTP/SOCKS5) + 主机 + 端口 + **代理范围**（npm 安装/下载、Node 下载部署、内核更新检查）。当前 npm 范围实际走代理；Node 下载与更新检查的代理支持为后续项。

## 环境（Environment）

运行内核所用的 Node 来源。**三个标签就是三个选项**（点标签即切换；改完需重启 dsh 生效）：

- **程序内置**：显示 Electron 自带的 Node 版本与 Chromium 版本。两者随应用一起升级，不能单独更新。
- **系统自带**：显示系统 Node 的当前版本与最新 LTS；若落后于最新版会出现「前往下载」按钮。系统安装的 Node 由你自行升级（安装包 / winget / nvm / brew 等）—— 应用不碰系统安装目录；想让它代管请改用「本地部署」。
- **本地部署**：同样显示当前版本与最新 LTS；未部署或落后时出现「部署 Node / 更新到 vX」按钮。此外可**选择任意版本下载 / 切换**（列表来自 nodejs.org，可勾选「包含非 LTS（Current）」）；切换会把配置目录里已部署的那份 Node **整体替换**，不做多版本并存 —— 若 dsh 正跑在这个本地 Node 上，会先询问并停止 dsh，装好后自动重启。

> 「最新 LTS」取自 nodejs.org 的发行索引，主进程缓存 10 分钟；离线或代理不通时显示「无法获取最新版本」。
> 运行内核需要 **Node ≥ 20**：在版本列表里选中更低的主版本会给出提示 —— 装了也跑不起内核。

改完运行环境，点页面下方的**「立即应用」**即重启 dsh 让新的 Node 立刻生效。若所选运行时不可用（未检测到系统 Node ≥ 20，或本地还没部署），按钮会**禁用**并说明原因 —— 因为应用就是重启 dsh，运行时不合法时会直接启动失败。

### npm 来源

运行内核时用的 npm。**同样是三个标签就是三个选项**：

- **程序内置**：首次使用时从 registry 下载并缓存到配置目录，由应用代管。
- **系统自带**：使用系统安装的 npm；更新会执行一次全局安装 —— **会真实改动你系统的全局 npm**。
- **本机 Node 自带**：使用「本地部署」那个 Node 自带的 npm；更新会装进配置目录里的那个 Node，由应用代管。

每个标签都显示**当前版本**与 **registry 上的最新版**；落后或尚未就绪时出现「下载 npm / 更新 npm」按钮。下方还有一个三个标签共用的**版本选择器**（可勾选「包含预发布」），能安装任意历史版本 —— 安装作用于**上方选中的那个标签**对应的来源。

> npm 来源只在「内核来源 = 内置」时装内核会用到；改动**不需要**重启 dsh，下次安装 / 更新内核时生效。
> 若「系统自带」报权限错误（EPERM），通常是因为 npm 的全局 prefix 指向了系统 Node 目录：需要以管理员身份运行，或改用另外两个来源（它们都装进配置目录）。

## 内核（Kernel）

- **启动 / 停止 / 重启**：直接控制 dsh；状态标签实时显示。
- **立即应用**：运行类配置改动后点此保存并重启 dsh。
- **内核来源**：内置（装到应用目录、用内置 Node）或 全局。
- **启动器路径**：仅在「全局」模式显示，用文件选择器选取。
- **内核更新**：启动时检查、包含测试版；手动「检查 / 更新内核」。**已是最新时不再弹提示**，结果在「检查」按钮下方回显一行（含远端解析到的版本号）。
- **选择版本 / 卸载**：浏览并**安装 / 切换**到任意历史版本；**卸载**会先自动停止 dsh，卸载后显示安装引导。

::: warning 升级 / 切换 / 卸载时
这些操作会**先强制停止所有运行中的 dsh 实例**（正在运行会先弹确认）。成功后会自动重启 dsh 以运行新版本；失败会检测占用原因并给出提示。
:::

## 终端（Terminal）

- dsh 的实时输出（stdout / stderr），带 ANSI 颜色；可切换**自动滚动**，也可**清空显示**。
- 终端是**只读**的（不接受键盘输入）；dsh 还没输出时显示占位提示。
- 切走再回来会重新拉取最近输出（服务端环形缓冲，上限 5000 行）。
- 标题栏已不再放终端按钮：按 `Ctrl` / `Cmd` + `T` 即可在 DeepSeek UI 与终端之间切换。

## 快捷键（Shortcuts）

| 快捷键 | 默认 | 范围 |
|---|---|---|
| 返回主窗口 | `Ctrl` / `Cmd` + `Alt` + `H` | **系统全局** —— 任何程序里按下都把本应用主窗口调到前台（最小化或隐藏到托盘也能拉回来） |
| 切换终端视图 | `Ctrl` / `Cmd` + `T` | 应用内：在 DeepSeek UI 与「设置 · 终端」之间切换 |
| DevTools 控制台 | `F12` | 应用内：仅在「关于 → 开发模式」开启时生效 |

- 点「**修改**」后按下组合键即可（`Esc` 取消）；「**清空**」= 禁用，「**恢复默认**」= 回到上表的默认值。
- 只支持 **字母 / 数字 / F1–F24**，且**必须带至少一个修饰键** —— 否则打字时会被抢走。
- 系统全局那个可能被别的程序占用；占用时页面会直接告诉你，换一个组合即可。
- 改动**即时生效**，不需要重启应用。

## Webview

内嵌页面（内核 UI、网页对话、以及所有动态标签）的渲染方式与浏览器标识。

- **硬件加速**：默认开启。关闭后资源占用更低、对老旧驱动的兼容性更好，但滚动与动画会变卡。它**只能在应用启动时决定**，所以改动需要**重启应用**（页面会提示并可直接重启）。
- **UserAgent**：留空即使用默认值。默认值按当前平台与版本实时生成，形如：

  ```
  Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0.6723.58 Safari/537.36 XEonSKY/0.1.5-alpha-5
  ```

  平台段按各平台真实 Chrome 的写法生成；`Chrome/` 后是当前 Chromium 版本，`XEonSKY/` 后是应用版本。
- 自定义 UA 对**新请求**立即生效；已经加载好的页面要刷新（或重启）才会带上新 UA。

## 关于（About）

- 显示应用版本与运行架构。
- **自动更新**：启动时检查应用新版本并后台下载；**检测测试版**、**开发模式**（默认 `F12` 开关 DevTools，快捷键可在「快捷键」页更改）。

> 设置卡片均可点标题折叠。主题与语言的基础来源仍是 dsh 的 `~/.dsh/settings.yaml`；应用自身设置（常规/网络/内核/关于等）存于**应用配置目录** `settings.json`（默认 `~/.config/dsh_shell`，开发态 `dsh_shell_dev`，可在向导/设置中选择配置目录并迁移）。
