快速开始 ​

安装完成后，第一次启动应用即可使用。

第 1 步：启动 ​

双击桌面图标或开始菜单快捷方式启动。应用会自动拉起并嵌入 DeepSeek Harness Web UI。

  • 首次启动若未检测到内核，会显示全屏安装引导。
  • 选择镜像源（官方 registry.npmjs.org 或 npmmirror 镜像）、是否包含测试版与要安装的版本，点击安装内核。
  • 安装完成后应用自动启动 dsh，出现 Web UI 即代表就绪。

第 2 步：标签页 ​

窗口顶部是无边框自绘标题栏，左侧即浏览器式标签条：

  1. DeepSeek UI —— 内嵌的 DeepSeek Harness 主界面（默认）。
  2. 网页版对话 —— 内嵌 chat.deepseek.com，用于网页对话。
  3. 用量 / 充值 —— 内嵌 platform.deepseek.com，查看用量与充值余额。

这三个是固定标签，始终存在、不可关闭。此外：

  • 页面里点开的新链接（target=_blank）会自动变成一个动态标签；
  • 点标签条上的「＋」可主动新建——默认打开内置导航页（带搜索框与常用站点），也可在设置里改为打开自定义网址；
  • 标签可以拖动排序；拖到另一个窗口顶部的浅蓝遮罩，还能把标签移入那个窗口；
  • 右侧依次是设置、最小化 / 最大化 / 关闭按钮（终端已收进设置页，见设置说明）。

快捷操作

按住 Ctrl（macOS 为 Cmd）点击任意标签，会用系统默认浏览器打开该标签的网址；普通点击则在应用内切换。

完整说明见标签页与多窗口。

第 3 步：可选设置 ​

进入 设置 可调整工作目录、端口、外观、内核更新与开发模式等，详见设置说明。

现在可以开始了 ​

在 DeepSeek Harness Web UI 内进行对话、使用工作区文件系统等功能。有疑问先看常见问题。
