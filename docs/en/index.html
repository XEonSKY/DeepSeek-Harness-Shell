DeepSeek Harness ShellDesktop shell around DeepSeek Harness

Launch the dsh kernel with Electron and put DeepSeek Harness Web UI, web chat and the top-up platform into one desktop window.

Download
Quick start
🧩

Browser-style tabs

The three fixed sites (kernel UI / web chat / usage & top-up) live in the tab strip; links opened from a page become dynamic tabs you can open freely, star to keep alive, and drag to reorder.

🪟

Multiple windows

Right-click "Open in new window" to tear off a full secondary window; tabs can be dragged between windows, and the earliest secondary window takes over once the core window closes.

🔄

Self-managed kernel

Install / upgrade / switch / uninstall the @deepseek-ai/dsh kernel, safely stopping a running server first.

🌓

Light and dark themes

Follow system / light / dark, with the app icon switching between its light and dark art; embedded pages follow the shell's colour scheme.

🔒

Privacy-minded

Hide to system tray; theme and language sync with dsh's own config over localhost only.

⬇️

Keeps up to date

Dual update checks for the app (GitHub) and the kernel (npm) to stay current.
