DeepSeek Harness Shell桌面外壳 · 内嵌 DeepSeek Harness

用 Electron 拉起 dsh 内核，把 DeepSeek Harness Web UI、网页版对话与充值平台装进一个桌面窗口。

下载应用
快速开始
🧩

浏览器式标签页

三个固定站（内核 UI / 网页版对话 / 用量充值）常驻标签条；页面里打开的新链接自动成为动态标签，可任意开、可星标保活、可拖动排序。

🪟

多窗口

右键「在新窗口打开」即可拆出完整副窗口；标签能在窗口之间拖动迁移，核心窗口关闭后由最早的副窗口自动接管。

🔄

自管理内核

自动下载 / 升级 / 切换 / 卸载 @deepseek-ai/dsh 内核，操作前自动安全停止运行中的服务。

🌓

深浅色主题与图标

主题可选跟随系统 / 浅色 / 深色，应用图标随之切换深浅两版；内嵌网页的深浅色与外壳保持一致。

🔒

专注隐私

可关闭到系统托盘，界面语言与主题同步 dsh 自己的配置，仅用本地 127.0.0.1。

⬇️

持续更新

支持应用与内核的双重更新检查（GitHub / npm），跟随官方发布保持最新。
