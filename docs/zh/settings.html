设置说明 ​

在 设置 页通过左侧分组调整：常规、外观、网络、内核、关于。

常规（General） ​

  • 工作目录：dsh 启动所在目录；留空用配置目录下的 workspace。
  • 端口：自动（推荐，从 3080 起挑空闲端口）或手动指定。
  • 关闭按钮行为：隐藏到托盘或直接退出；可选择「每次询问」或「记住选择」。

新标签页与搜索 ​

  • 默认搜索引擎：地址栏输入非网址内容、以及内置导航页搜索时使用的引擎（百度 / 搜狗 / 360 / Bing / Google / DuckDuckGo）。
  • 新标签页：点标签条「＋」时打开什么——内置导航页（带搜索框与常用站点）或自定义网址（填写固定 URL）。
  • 常用站点快捷方式：名称 + 网址的列表，显示在内置导航页上，点击直达。

其它 ​

  • 恢复默认设置：一键重置并重启 dsh。

外观（Appearance） ​

  • 主题：跟随系统 / 浅色 / 深色，切换即时生效。
  • 语言（二级下拉）：选择 中文 / English，并选择扩展翻译（zh：简体/二次元/文言/繁体中文；en：English/海盗腔/莎翁腔）。扩展翻译为文本覆盖，仅当前语言生效，不改 dsh 设置。
  • 界面缩放：50%~200%（作用于外壳窗口与内嵌 webview）。
  • 禁用系统缩放：开启会提示重启生效（忽略操作系统显示缩放）。

网络（Network） ​

  • npm 镜像源：官方 registry / npmmirror。
  • 代理：启用 + 协议(HTTP/SOCKS5) + 主机 + 端口 + 代理范围（npm 安装/下载、Node 下载部署、内核更新检查）。当前 npm 范围实际走代理；Node 下载与更新检查的代理支持为后续项。

内核（Kernel） ​

  • 启动 / 停止 / 重启：直接控制 dsh；状态标签实时显示。
  • 立即应用：运行类配置改动后点此保存并重启 dsh。
  • 内核来源：内置（装到应用目录、用内置 Node）或 全局。
  • Node 运行时：Electron 自带 / 系统（≥20）/ 本地部署；npm 来源：系统 / 内置（下载）/ 本地 Node 自带。
  • 启动器路径：仅在「全局」模式显示，用文件选择器选取。
  • 内核更新：启动时检查、包含测试版；手动「检查 / 更新内核」。
  • 选择版本 / 卸载：浏览并安装 / 切换到任意历史版本；卸载会先自动停止 dsh，卸载后显示安装引导。

升级 / 切换 / 卸载时

这些操作会先强制停止所有运行中的 dsh 实例（正在运行会先弹确认）。成功后会自动重启 dsh 以运行新版本；失败会检测占用原因并给出提示。

关于（About） ​

  • 显示应用版本与运行架构。
  • 自动更新：启动时检查应用新版本并后台下载；检测测试版、开发模式（F12 开关 DevTools）。

设置卡片均可点标题折叠。主题与语言的基础来源仍是 dsh 的 ~/.dsh/settings.yaml；应用自身设置（常规/网络/内核/关于等）存于应用配置目录 settings.json（默认 ~/.config/dsh_shell，开发态 dsh_shell_dev，可在向导/设置中选择配置目录并迁移）。
