# 内核（@deepseek-ai/dsh）管理

本应用内置对内核 `@deepseek-ai/dsh` 的检测与版本管理。内核驱动 DeepSeek Harness Web UI。

## 常见操作

### 首次安装
未检测到内核时，应用内会弹出安装引导，可选镜像源、是否含测试版与指定版本，一键安装。

### 升级 / 切换版本
在 **设置 → 内核** 中：

- **检查 / 更新内核**：对比当前与最新版本，点「更新内核」执行升级。
- **版本管理**：刷新版本列表（受「检测测试版」与镜像源影响），选中历史版本即可安装 / 切换（升级或回退）。

升级与切换都会**先安全停止 dsh**（正在运行时先弹确认），成功后自动重启以运行目标版本；失败则尽量恢复原运行态并给出原因。

### 卸载
点「卸载内核」会先停止 dsh 再移除，之后回到安装引导。若卸载失败，应用会检测目录占用原因（如仍有进程引用、只读或安全软件锁定）并提示。

## 网络与镜像

内核的版本列表、更新检查与安装 / 卸载都走 npm。默认官方源 `registry.npmjs.org`，国内可切换 `npmmirror` 镜像。

## 与“应用自更新”的区别

- **内核更新**：更新 `@deepseek-ai/dsh`（npm 安装/升级），在「内核」页管理。
- **应用自更新**：更新本外壳应用本身（GitHub 发布），在「关于」页管理。
