# Quick start

Once installed, the app is ready on first launch.

## Step 1: Launch

Start from the desktop icon or Start Menu. The app brings up and embeds the DeepSeek Harness Web UI.

- On first run, if **no kernel is detected**, a full-screen install wizard appears.
- Choose a registry (official registry.npmjs.org or the npmmirror mirror), whether to include pre-releases, and a version, then click **Install kernel**.
- After installation the app starts dsh automatically; the Web UI appearing means you are ready.

## Step 2: Tabs

The frameless title bar starts with a **browser-style tab strip**:

1. **DeepSeek UI** — the embedded DeepSeek Harness main interface (default).
2. **Web chat** — embeds [chat.deepseek.com](https://chat.deepseek.com/).
3. **Usage / top-up** — embeds [platform.deepseek.com](https://platform.deepseek.com/) for usage and balance.

These three are **fixed tabs**: always present, never closable. Beyond them:

- Links opened from a page (`target=_blank`) automatically become a **dynamic tab**;
- **+** in the tab strip opens a new one — by default the **built-in new tab page** (search box plus shortcuts), or a **custom URL** if you change that in Settings;
- Tabs can be dragged to reorder, or dragged onto another window's light-blue overlay to **move the tab into that window**;
- On the right: Settings, minimize / maximize / close (the terminal now lives inside Settings — see [Settings](/en/settings)).

::: tip Shortcut
Hold **Ctrl** (**Cmd** on macOS) while clicking any tab to open that tab's URL in your system browser; a normal click switches in-app.
:::

See [Tabs & multiple windows](/en/usage) for the full picture.

## Step 3: Optional settings

Open **Settings** to adjust working directory, port, appearance, kernel updates and developer mode — see [Settings](/en/settings).

## You're ready

Chat and use the workspace in the DeepSeek Harness Web UI. See the [FAQ](/en/faq) if anything looks wrong.
