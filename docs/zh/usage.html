标签页与多窗口 ​

应用是无边框桌面外壳，窗口上部是自绘标题栏（内置浏览器式标签条），下部是 web 内容区。

标题栏（左侧 → 右侧） ​

区域说明
应用图标 + 标题显示应用名
固定站图标仅核心窗口显示：DeepSeek UI / 网页版对话 / 用量充值
跳转核心窗口仅副窗口显示，用于回到承载 DeepSeek UI 的那个窗口
标签条动态标签 + 「＋」新建；空白处可拖动窗口、滚轮横向滚动
刷新仅当前激活的是三个固定站之一时显示，用于重载该页
终端打开 dsh 实时输出（stdout / stderr）视图
设置打开设置页
最小化 / 最大化 / 关闭窗口控制

进入终端 / 设置是覆盖层：底下的网页不会卸载，切回来仍是原状态。

标签页 ​

固定标签（仅核心窗口） ​

三个固定站始终存在、不可关闭：

  1. DeepSeek UI —— 内嵌的 DeepSeek Harness 主界面。
  2. 网页版对话 —— 内嵌 chat.deepseek.com。
  3. 用量 / 充值 —— 内嵌 platform.deepseek.com。

动态标签 ​

  • 来源：页面内链接的 target=_blank / window.open，或点标签条上的「＋」。
  • 数量不设上限。
  • 保活策略：同时保活的网页为「固定站 + 你加星的标签 + 最近 3 个未加星的动态标签」。超出范围的标签仍然保留在标签条上，只是其网页被回收，切回时会重新加载。
  • 标签只有被打开过之后才会真正加载网页。

「＋」新建标签 ​

按设置里的「新标签页」决定打开什么：

  • 内置导航页（默认）——带搜索框、可切换搜索引擎、并显示你配置的常用站点；
  • 自定义网址——直接打开你填写的固定 URL。

标签操作 ​

操作效果
单击切换到该标签
Ctrl / Cmd + 单击用系统默认浏览器打开该标签的网址
中键单击关闭标签
星标（☆）保活固定：该标签的网页常驻，且不占用最近 3 个保活名额
拖动标签在标签条内重新排序；拖到另一个窗口顶部的浅蓝遮罩上，可把标签移入该窗口
右键复制标签 / 关闭 / 在新窗口打开 / 移动到其它窗口

地址栏 ​

地址栏仅在动态标签激活时显示（固定站不显示）。

输入行为
http(s): / about:在应用内加载
其它协议（mailto:、tel:、自定义协议等）交给系统默认程序打开
不是网址的内容用设置的默认搜索引擎搜索

地址栏左侧还有 后退 / 前进 / 刷新（加载中变为停止）。

多窗口 ​

  • 在标签上右键「在新窗口打开」，即可开出一个完整副窗口（自带标签条）。
  • 副窗口没有内核 UI 等三个固定站，标题栏位置显示「跳转核心窗口」按钮。
  • 副窗口的窗口标题会显示「当前标签页标题 - 软件名」。
  • 核心窗口被关闭后，最早打开的副窗口会自动接管成为新的核心窗口，并获得三个固定站。

键盘快捷键 ​

快捷键作用
Ctrl / Cmd + T在 DeepSeek UI 与终端之间切换
F12打开 / 关闭 DevTools 控制台（仅当「开发模式」开启时生效，见设置）

托盘 ​

关闭到托盘后，可通过系统托盘图标：

  • 单击：显示 / 隐藏窗口；
  • 右键菜单：「显示/隐藏窗口」「退出（同时结束 dsh）」。

关闭窗口并不结束 dsh；真正退出时应用会同步结束它管理的 dsh 进程，避免残留。 若没有可用托盘，关闭最后一个窗口会直接退出应用。
